# Código Creativo 2027

Este repositorio contiene ideas y propuestas de clases para la clase Código Creativo 2027. Es la continuación que todos los grupos ya tomaron con Código Creativo de primer semestre. 

Promueve el trabajo por proyectos y busca enfocarse en tres carreras específicas: Cine, Arquitectura de Interiores y Arquitectura.

Vamos a utilizar Processing como herramienta principal y dependiendo de los proyectos, vamos a discutir si es viable migrar a otro entorno de programación.

En este curso, a diferencia del semestre anterior, vamos a partir del Design Thinking para aterrizar prototipos.

Vamos a trabajar por iteraciones y vamos a tener dos entregas: una parcial al inicio del semestre y una final al concluir el curso. Son 16 sesiones.

En esta parte del repositorio voy a poner reflexiones y notas para mí, en la carpeta docs va a estar el sitio que aparecerá públicamente con los estudiantes. Este sitio será una interfaz en la que podremos ver el contenido de la clase y va a servir como un sitio web.
