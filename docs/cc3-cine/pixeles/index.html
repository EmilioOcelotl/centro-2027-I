Rejilla de pixeles

Una imagen digital no es una superficie: es una lista de pixeles numerados de 0 en adelante, en orden de lectura. Dimensiona la rejilla, píntala y mira cómo cada pixel encuentra su número.

Color
Pintar

Los números se ocultan solos: a este tamaño el pixel ya no tiene dónde escribirlos.

Click para pintar, arrastrar para pintar varios. Alt + click toma el color de un pixel ya pintado. Con la rejilla enfocada, las flechas mueven y Enter pinta. La tecla c oculta y devuelve los controles.
